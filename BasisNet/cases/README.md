# Cases

## Available

- [2D airfoil](2D_airfoil/README.md): continuously parameterized airfoil
  thickness and angle of attack, trained with an explicit CuPy/CUDA backend.

The planned repository scope also includes a 2D ten-circle case and a 3D
ten-ball case. They will be added separately when their cleaned CUDA versions
are ready.

Each published case keeps its source, configuration, scripts, tests, and
protocol metadata together. Generated datasets, checkpoints, training logs,
frames, and videos are excluded from Git.
