# Eigenfluid results

This directory collects the machine-readable metrics and publication figures
for the latest Geometry-conditioned Eigenfluid Net (GEN) experiments.

| Case | Contents |
| --- | --- |
| [2D Airfoil](2D_Airfoil/README.md) | strict K=2048 three-objective training, nested-prefix reconstruction, rollout metrics, checkpoints, and media |
| [2D Metaball](2D_Metaball/README.md) | K=1024 and K=2048 held-out reconstruction errors |
| [3D Metaball](3D_Metaball/README.md) | five K=1024 configurations, metrics, and six-panel figure |

Every bundle includes a SHA-256 manifest.
